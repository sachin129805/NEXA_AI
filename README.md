# NexaAI

A full-stack multimodal AI platform with:

- Custom LLM
- NLP pipeline
- Universal RAG
- Persistent memory
- Personalization
- Multimodal AI
- Image generation
- AI agents
- Web search
- Code execution
- AI document generation
- AI presentation generation
- AI spreadsheet generation
- Model comparison
- Authentication
- OTP
- MFA
- Analytics

## Structure

frontend/  - Next.js application
backend/   - FastAPI application
ai/        - AI/ML systems
docs/      - Architecture and project documentation

## Development principle

The application is designed to be dynamic and configuration-driven.
Production data should come from APIs, databases, model services, configuration,
or user state rather than hardcoded UI content.
